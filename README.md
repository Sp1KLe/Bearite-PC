# Bearite-PC

Лаунчер Bearite для ПК (Windows). Неофициальный фанатский проект для Super Bear Adventure.

## Как это работает

Игра написана под Android, поэтому лаунчер запускает её в урезанном Android-эмуляторе. Игрок видит окно лаунчера, нажимает «Играть с модами», а всё остальное лаунчер делает сам:

1. При первом запуске скачивает у Google эмулятор, `adb` и системный образ Android 11 (Google APIs, x86_64, с переводом ARM-кода). Перед этим спрашивает согласие.
2. Скачивает файл игры (самый большой `.apk`) из релиза `v1` репозитория `Sp1KLe/Bearite`. В этом репозитории файлов игры нет.
3. Создаёт виртуальное устройство, загружает Android, ставит игру и запускает её.

Пока игра запускается без модов, их подключим следующим этапом.

Лог лаунчера показывает только действия самого лаунчера. Вывод игры он не читает.

## Что нужно на ПК

- Windows 10 или 11 (используются встроенные `curl.exe` и `tar.exe`).
- Включённая виртуализация (в BIOS) и компонент Windows «Платформа низкоуровневой оболочки Windows».
- Около 2–3 ГБ на загрузку и до 6 ГБ места на диске.

Всё лежит в папке `%LOCALAPPDATA%\Bearite-PC`. Чтобы удалить, достаточно стереть эту папку.

## План

1. Окно лаунчера (готово).
2. Запуск игры в урезанном Android (в работе, нужна проверка на реальном ПК).
3. Моды Bearite внутри этого запуска.
4. Сохранения, настройки, раскладка клавиш, окно игры внутри лаунчера.

## Как собрать .exe

Компьютер не нужен. На GitHub откройте **Actions → Build Bearite-PC → Run workflow**, после сборки скачайте артефакт **Bearite-PC** (внутри `bearite-pc.exe`).

## Структура

- `src/` — окно лаунчера (HTML, CSS, JS).
- `src-tauri/` — оболочка на Rust и Tauri 2; `src/launch.rs` отвечает за запуск игры.
- `.github/workflows/build.yml` — сборка под Windows.
