# Bearite-PC

Лаунчер Bearite для ПК (Windows). Неофициальный фанатский проект для Super Bear Adventure.

## Что уже есть

- Окно лаунчера: сайдбар, главная страница, страницы «Моды», «Лог», «Настройки», «Помощь».
- Кнопки «Играть с модами» и «Загрузить сохранение» пока заглушки: запуск игры подключим следующим этапом.

## План

1. Окно лаунчера (готово).
2. Урезанный Android внутри лаунчера и запуск в нём Super Bear Adventure.
3. Моды Bearite внутри этого запуска.
4. Сохранения, настройки, раскладка клавиш.

## Как собрать .exe

Компьютер не нужен. На GitHub откройте **Actions → Build Bearite-PC → Run workflow**, после сборки скачайте артефакт **Bearite-PC** (внутри `bearite-pc.exe`).

## Структура

- `src/` — окно лаунчера (HTML, CSS, JS).
- `src-tauri/` — оболочка на Rust и Tauri 2.
- `.github/workflows/build.yml` — сборка под Windows.
